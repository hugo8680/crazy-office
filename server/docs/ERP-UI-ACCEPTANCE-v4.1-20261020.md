## 1 本轮范围与需求覆盖

工程继续只有 `client` 与 Go `server` 两个项目，各自开发、测试、构建、发布和回滚。产品仍以 2D／3D 办公室为主界面，业务工作台在场景内展开。

本轮覆盖 PRD 1.0 中以下旧交互约定：

- 账号登录、邀请兑换、本人改密和退出都在办公室中办理。旧 `/login` 回到 `/`，不再提供独立登录流程。
- 底部操作栏统一承载业务入口、视角、缩放、旋转、网络连线、全屏和账户。删除左上模型及虚拟员工入口、右上工作入口和独立产物入口；工作台不再重复模块侧栏。
- 页面只呈现业务资料、办理结果、缺项、审批及实际台账。模型名称、岗位分工、工具调用、执行日志和功能介绍不作为产品页面内容。
- 点击场景对象进入对应业务；点击员工进入其有权查看的资料及工作。审批与结果在当前单据中出现，不靠“查看进展”寻找结果。
- 本版本不提供实验室业务入口。旧运行与接口作为受权限保护的历史兼容能力保留，不作为 ERP 八链的完成证明。旧实验室自动派工须在发布时暂停并保存原配置，避免产生 ERP 中不可见的新工作。

PRD 中的八条业务链、身份与权限、两级审批、事务、版本和防重复要求继续有效。以上是本轮界面增量，不意味着实现了 PRD 之外的制造、完整财务核算或外部业务执行。
