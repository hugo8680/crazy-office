- 工作区仅有 `client`、`server` 两个项目目录，分别维护依赖、开发、测试、构建、部署和回滚。
- 客户端 JavaScript 检查、144 项测试及独立构建通过。32 个页面与静态素材的 SHA-256 与拆分前完全一致，生产 HTTP 返回内容也逐项匹配；`.mjs` 类型正确。
- Go `make check`、`go vet`、`go test -race ./...` 通过：12 个有测试包、185 个含子用例的通过事件，失败为 0；另一个验收命令包无测试文件。不是沿用旧版 443 项数字。
- Go 原生构建及 Linux amd64 静态交叉构建通过，发布清单逐文件校验通过。服务端不运行旧 Node／Python 服务。
- 21 项独立迁移契约覆盖坏行与金额、实际 Excel 数值、SQL 范围与回滚、需求追溯、报价、网络回放、历史产物及真实报告错误的回归。
- 发布脚本完成 12 项隔离演练；实际服务器已验证首次失败自动回退及修正后的再次切换。Dockerfile 已提供，未执行镜像启动验收。

已核对项目立项、采购、销售、领用、归还、盘点、交付、事实周报和岗位资源准备。采购参考 96,000 元、销售 39,000 元、领用参考 24,000 元；最终库存 6 台，借 2、归 1、未还 1。交付区分盘点历史快照与已过账差异；周报区分 7 份单据与 6 种类型，不把不统计金额说成零金额。18 条审批按链由不同隔离账号办理，无申请人自批。

前四轮的金额单位、历史库存误判、周报口径及提前结束等失败证据保留；这些结果未被覆盖为成功。修复后增加回归、重新调用模型并独立检查。

## 本机与生产验证

本机浏览器检查了窄屏与 1440×900 桌面断点、2D／3D 切换、员工及模型状态、业务工作台和八类业务入口。临时视口已恢复。生产浏览器未另行验收，生产证据来自经过 HTTPS 的认证 API、全部静态资源摘要、原生进程和 SSH 检查。

正式入口为 `https://office.laisengou.com/`，发布版本 `20261020-v4.0.0-go-r2`：

- 客户端：`/opt/office.laisengou.com/client/current`，Nginx 直接提供静态文件。
- Go：`/opt/office.laisengou.com/server/current`，`office-api.service` 已启用，监听 `127.0.0.1:8080`。旧 Node 服务停用，旧发布保留。
- 私有数据和 `office.env` 沿用原位置。旧签名会话在隔离预检和生产均通过；原账号及业务数据未被测试资料替换。
- 旧接口返回的 60 条任务可读取；历史文件、ZIP、SSE 在服务器隔离副本验证通过。原有文件另有完整冷备。
- Go 备份 API 在副本上实际生成 SQLite 与身份备份，完整性为 `ok`、权限 `0600`、公开回执无服务器私有路径。
- 登录前页面跳转 `/login`，登录后办公室与 API 正常；模型在服务器无代理实际连接成功。
- 其他站点配置摘要、九个容器标识及私有环境文件摘要均保持一致。

迁移保存完整冷备、原站点及原服务单元。首次切换的域名健康检查命中了尚未退出的 Nginx 旧工作进程，自动回退到旧服务；增加新配置生效后的有界重试后重新发布成功。切换时没有活动任务，不将任务中断或模型失败覆盖成成功。

自动派工已恢复原配置：3–5 分钟随机运行 database／delivery／procurement。切换后触发原调度器，实际选中内部交付计划任务 `8dd3712f-aecf-4039-be5e-19d3f6855f1a`，五个岗位任务均完成，生成需求底稿、计划 CSV／JSON、审查回执及 HTML／Markdown 草案。执行状态 `completed`，业务结果 `needs_review`，仍待真实负责人确认范围、估算与验收条件，没有伪造客户确认或对外承诺。后续开发按测试、备份、等待任务、部署、验收的顺序执行，两个项目可分别更新。
