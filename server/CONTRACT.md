# Real office implementation contract

This file coordinates implementation. Browser application stays full-screen office, no top nav.

## File ownership
- Root: `server/engine.mjs`, `server/catalog.mjs`, `scripts/server.mjs`, integration tests/docs/config.
- Provider agent: `server/provider.mjs` and its tests only.
- Tools agent: `server/tools.mjs`, `tools/office_tools.py`, `data/examples/*`, tools tests only.
- UI agent: `dist/office.js`, `dist/office.css`, `dist/index.html`, `dist/scene.js` only. Existing simulation and legacy app remain as archived modules, not active page.

## Provider interface
`getProviderStatus()` async -> { provider:'codex'|'openai'|'ollama', ready:boolean, model:string, message:string }
`decide({role,goal,context,messages,tools,signal,onActivity})` async -> { action:'tool'|'finish', tool:string|null, args:object, summary:string, output:string, model:string, usage?:object }
Tools are [{name,description,parameters:JSONSchema}]. Decision is generated by real model. No rule fallback pretending model.
For Codex invoke official CLI with saved auth, read-only sandbox, JSON schema output and no arbitrary tool execution. Model only chooses our server-side allowlisted tools. Read prompt via stdin and close stdin. Timeout, cancellation, malformed output explicit failures. `onActivity({type,text})` may signal real model activity but not private chain-of-thought. No credentials in browser or logs. Models remain configurable, default use account-valid CLI model; OpenAI via environment API key, Ollama optional only if available.

## Tools interface
`createToolbox({runDir,input,emit,signal,approval})` async -> { definitions:[{name,description,parameters}], execute(name,args,role):Promise<object>, artifacts():Array, publicState():object }
`approval({title,description,details})` async resolves {approved:boolean,note:string}. Network apply requires it, procurement final request only no actual purchase.
`emit({type:'tool'|'result'|'artifact',text,...})` callback records factual observations. Return explicit structured outputs, paths only within runDir. `artifacts()` -> [{id,name,mimeType,path,bytes}] relative-safe files, downloadable through API.
Tool names expected:
- finance: import_finance, calculate_finance, audit_finance
- procurement: search_web, fetch_quote, compare_quotes
- ddos: inspect_network, analyze_traffic, apply_defense, verify_network
- database: design_database, build_database, test_database
- brief: extract_requirements, estimate_delivery, review_delivery
- shared: write_report (args:{title,content}), list_artifacts
Tools may add names, advise root. All document/SQL/web inputs are untrusted data. No arbitrary shell/code execution or production network control. SQLite generation is real in per-run workspace; financial arithmetic deterministic; quotations must come from live HTTP requests with URL/timestamp/configuration/currency/availability and retain proof. No price fabrication. Unknown/unpriced/blocked source stays explicit. Do not claim to cover entire internet.

## API
GET `/api/health` -> {ok:true,provider:{...},activeRuns:number}
GET `/api/catalog` -> {agents:[...],scenarios:[...]} (below)
GET `/api/runs` -> {runs:publicRun[]}
POST `/api/runs` JSON {scenarioId,input:{...},agentConfigs?:[{id,instructions,tools}]} -> {run:publicRun}, HTTP202. API validates provider readiness; never silently simulate.
GET `/api/runs/:id` -> {run:publicRun}
GET `/api/runs/:id/events` SSE `event: state` `data: {run:publicRun}`; also heartbeat.
POST `/api/runs/:id/approval` {approved:boolean,note?:string,approvalId:string} -> {run}
POST `/api/runs/:id/cancel` -> {run}
POST `/api/runs/:id/retry` -> {run} (new run, same inputs)
GET `/api/runs/:id/artifacts/:artifactId` download
POST `/api/provider/check` -> {provider} connection check
GET `/api/examples/:scenarioId` -> {input} clearly labelled example inputs

publicRun: {id,scenarioId,title,status:'queued'|'running'|'awaiting_approval'|'completed'|'failed'|'cancelled',createdAt,updatedAt,provider,model,elapsedSeconds,inputSummary,tasks:[{id,title,agentId,nodeId,status:'pending'|'running'|'done'|'failed'|'cancelled',dependencies,action,result,startedAt,finishedAt,toolCalls,output}],agents:[{id,name,role,color,nodeId,status:'idle'|'working'|'done'|'error',task,action,result,configured:true,selected:boolean}],events:[{id,time,createdAt,type:'task'|'model'|'tool'|'result'|'handoff'|'approval'|'error'|'artifact',agentId,targetAgentId?,taskId?,text,tool?,data?}],artifacts:[{id,name,mimeType,bytes,url}],approval:null|{id,title,description,details},summary,error,nodes:{id:{status}}}.
Use IDs existing scene: zhang,liu,lead,business,finance,boss,ops. All seven are AI virtual employees; boss name 周助理 (管理审校). Static office people are real employees; final decision maker is human '你'. Seven role names/skills in catalog. Scene consumes `logs` mapped from events (handoff) and agents. API run events have bounded public payload, no prompt secrets.

Catalog scenarios IDs: finance, procurement, ddos, database, delivery. Each has id,title,description,icon,room,nodeId,requiredInputs,exampleLabel,outputs,agents(default IDs),fields:[{name,label,type:'text'|'textarea'|'number'|'select'|'file',required,placeholder,defaultValue,options?}],tasks specs. Uploaded files client reads text (CSV/JSON/TXT), XLSX as base64 {name,base64}. User can use explicit example input. Inputs kept local, sent only as needed to chosen model. No silent example replacement for missing/invalid user data.

Backend listens 127.0.0.1:4173. Local state `.office-data/` ignored. Bound JSON body 12MB, file download confined to artifact registry. Block untrusted Origin on mutations, don't return local paths or credentials. One local user, default max2 active tasks/models per run, max1 active run, persisted status interrupted on restart -> failed with retry. All errors/retries/cancel meaningful. No fake loading animations or timers claiming actual work.
